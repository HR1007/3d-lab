展示櫃

玻璃前板、側板、層板、底座、燈帶全部是平面，用 3D transform 組起來。餅乾本來就是扁的， 用平面來做最自然：俯視圖整片轉 X 90° 平躺，一層 4×2，有幾處疊成 2～3 片一疊。 數值照 Figma「烘焙展示櫃」，整體放大 1.25 倍。

拖曳旋轉・方向鍵每次 10°・按 0 或雙擊回到預設角度

X −15°　Y −25°

做法重點

部位做法
餅乾俯視圖整片轉 X 90° 平躺。4 種各用 SVG <symbol> 畫一次、<use> 引用，等於 Figma 的 component 與 instance
餅乾的厚度每片底下墊一張同形狀的深色剪影，比頂面低 2.5，從斜上方看會在前緣露出一圈
一疊餅乾每片都是一個平面，一片往上墊 3；每片繞垂直軸轉一點、錯開一點，看起來是隨手疊的
玻璃半透明底色疊兩道斜向反光漸層；從內外都要看得到，所以不關背面
