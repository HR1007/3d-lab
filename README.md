# 日日餅乾：英文單字小遊戲

給國中小的英文單字填空小遊戲，整個場景用原生 CSS 3D 做（沒有 3D 函式庫）。
字母就是店裡的餅乾和麵包：a–m 是展示櫃頂上的字母餅乾、n–z 是麵包架上的字母麵包。

線上版：https://3d-lab-zeta.vercel.app

## 怎麼打開

直接雙擊 `index.html` 就能玩，不需要安裝或 build。
想用本機伺服器也可以：`python3 -m http.server 4317`，再開 http://127.0.0.1:4317/。

## 玩法

1. 店門口：點店門，門往店裡轉開，鏡頭走進店裡。
2. 導覽：字母餅乾 a–m（左邊展示櫃頂上）→ 字母麵包 n–z（右邊麵包架）→ 櫃台。可以略過。
3. 遊戲說明書：縫線邊框的小書，可以前後翻，每頁一張遊戲截圖（`images/howto/`）；最後一頁「開始遊戲」→ 3、2、1。
4. 營業：15 位顧客輪流到櫃台前，每位出一個挖空的英文單字（中文提示、🔊 可以聽發音）。
   按「餅乾櫃／麵包架」轉過去點缺的字母，小栗會走過去拿回來補上；點錯了商品會搖一搖。電腦也能直接按鍵盤字母。
5. 右上角：倒數時鐘（剩三成時變紅晃動）、齒輪設定（暫停：繼續、重新開始、遊戲說明、回到主畫面；Esc 也能開）。
6. 營業結束：星星、答對幾題、15 個單字複習（每個都能聽發音）。

規則：每位顧客 30 秒＋每個空格 10 秒；4 個字母以內挖 1 格、5–6 個挖 2 格、7 個以上挖 3 格，第一個字母一定給；
答對 13 題以上三顆星、9 題以上兩顆、1 題以上一顆。

## 檔案

| 檔案 | 做什麼 |
|---|---|
| `index.html` | 整頁就是遊戲舞台 |
| `scripts/props.js` | 餅乾、麵包的圖（SVG `<symbol>`）、展示櫃、商品表 |
| `scripts/shop.js` | 整間烘焙店（地板、天花板、三面牆、展示櫃、麵包架、櫃台、吊燈、小栗） |
| `scripts/storefront.js` | 店門口的店面、前廳、人行道、遮雨棚 |
| `scripts/characters.js` | 小栗和三位顧客（兔子、小熊、狐狸）的 6 層分層紙偶 |
| `scripts/letters.js` | 在餅乾、麵包上寫字母，變成可以點的商品 |
| `scripts/words.js` | 100 個生活單字（10 類各 10 個） |
| `scripts/game.js` | 開場：推門進店、導覽、接說明書 |
| `scripts/book.js` | 遊戲說明書翻頁 |
| `scripts/play.js` | 營業：出題、小栗去拿字母、計時、暫停、計分 |
| `styles/tokens.css` | 所有顏色、尺寸、時間的 token |

## 寫法約定

- 色彩、字級、間距、尺寸、時間都從 `styles/tokens.css` 引用，元件裡不寫死色碼或 px（border 的 1px 例外）。
- 3D 場景以「Figma 的 1px」為單位：`--su` ＝ 舞台寬度 ÷ 1200，舞台多寬場景就多大。
- 斷點只用 375／768／1200。手機版舞台撐滿整個螢幕。
- 沒有任何函式庫。JS 只產生重複出現的東西、決定遊戲流程的順序；動畫本身是 CSS transition／animation，狀態都寫在 data 屬性上。

## Figma → CSS

| Figma | CSS |
|---|---|
| 3D transform（Depth、X／Y／Z 旋轉） | `transform: translateZ() rotateX() rotateY() rotateZ()`，順序相同 |
| Keep nested layers 3D | `transform-style: preserve-3d` |
| Perspective | `perspective` |
| 背面不顯示 | `backface-visibility: hidden` |

### 為什麼店分成好幾層

整間店、店面全部放在同一個 3D 空間時，Chrome 排前後會出錯：某些舞台寬度下牆被漏畫一塊、店面右半邊被截掉、店裡的牆被畫到店外。
所以地板、天花板、每一面牆、擺設、店面、顧客……各自一層 `.shop__room`（套同一個鏡頭），依固定順序疊起來。
挑的順序都是「後面那層不可能擋住前面那層」，例如鏡頭永遠在牆面圍起來的那一側，所以擺設一定疊在牆面上面。
