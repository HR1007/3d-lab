# 日日餅乾：英文單字小遊戲

給國中小的英文單字填空小遊戲，整個場景用原生 CSS 3D 做（沒有 3D 函式庫）。
字母就是店裡的餅乾和麵包：a–m 是展示櫃頂上的字母餅乾、n–z 是麵包架上的字母麵包。

線上版：https://3d-lab-zeta.vercel.app

## 怎麼打開

直接雙擊 `index.html` 就能玩，不需要安裝或 build。
想用本機伺服器也可以：`python3 -m http.server 4317`，再開 http://127.0.0.1:4317/。

### 用 VS Code 打開

1. VS Code →「檔案 → 開啟資料夾…」選 `3d-lab` 這個資料夾（或在終端機打 `code ~/claude_figma/3d-lab`）。
2. 第一次打開，右下角會建議安裝 **Live Server**（設定在 `.vscode/extensions.json`），按安裝。
3. 右下角狀態列按「Go Live」，瀏覽器就會打開遊戲；之後改了檔案存檔，頁面會自動重新整理。

要改哪裡：顏色、尺寸、動畫時間都在 `styles/tokens.css`；單字題庫在 Supabase（見下面「單字題庫」）；背景音樂的樂譜在 `scripts/music.js` 上半段（`CHORDS` 和弦、`MELODY` 旋律、`BPM` 速度）。

## 玩法

1. 店門口：點店門，門往店裡轉開，鏡頭走進店裡。
2. 導覽：字母餅乾 a–m（左邊展示櫃頂上）→ 字母麵包 n–z（右邊麵包架）→ 櫃台。可以略過。
3. 遊戲說明書：縫線邊框的小書，6 頁，每頁一張遊戲截圖（`images/howto/`）。翻頁時右半頁真的掀起來、翻過書背蓋到左邊（手機版整頁往左翻走）。
4. 主畫面：說明書看完或跳過，都停在這裡。正中間一顆大大的「開始遊戲」，下面是現在的難度和單字量，還有「遊戲說明」「設定」「回到店門口」。
   按下開始遊戲：按鈕壓下去、彈開，碎成字母餅乾和星星飛出去，再 3、2、1。
5. 營業：顧客輪流到櫃台前，每位出一個挖空的英文單字（左上角是難度、中文提示、🔊 可以聽發音）；預設 15 位，前 5 位初級、中間 5 位中級、最後 5 位高級。
   按「餅乾櫃／麵包架」轉過去點缺的字母，小栗會走過去拿回來補上；點錯了商品會搖一搖、扣 3 秒。電腦也能直接按鍵盤字母。
6. 右上角：音樂開關、鬧鐘、齒輪。鬧鐘的鐘面色塊是剩下的時間（綠 → 過半變橘）；剩三成整顆變紅、鈴鐺晃、兩邊冒震動線條；最後 5 秒整顆跟著震；點錯時飄出「−3 秒」。
   齒輪＝暫停＋設定：繼續、重新開始、遊戲說明、回到主畫面；Esc 也能開關。
7. 營業結束：星星、答對幾題、這一局的單字複習（每個都能聽發音）；「回到主畫面」或「再玩一次」。

### 設定（主畫面的「設定」或右上角齒輪）

- **單字難度**拉桿 5 段：很簡單（只有初級）、簡單（初級＋中級）、普通（初級 → 中級 → 高級，預設）、困難（中級＋高級）、超難（只有高級）。
- **單字量**拉桿：一局 5–30 個，每格 5 個，預設 15。平均分給這個難度的幾個等級、由易到難出。
- 兩個選擇記在這台瀏覽器（localStorage `nichinichi-settings`）。營業中改了，從下一局開始；按「重新開始」馬上換。
- **記事本**：每答完一題（答對或時間到）就記下來，最近考的在最上面，可以只看「答錯過的」、按 🔊 再聽一次、清空（要按兩次）。
  也是存在這台瀏覽器（`nichinichi-notebook`），換電腦或清掉瀏覽器資料就沒了。[需確認] 要不要改存 Supabase

規則（2026-11-21 受訪者覺得太簡單，調難；數字都是 [需確認]）：
- 時間：每位顧客 20 秒＋每個空格 8 秒；點錯扣 3 秒。
- 挖空：3–4 個字母挖 2 格、5–6 挖 3 格、7–8 挖 4 格、9 以上挖 5 格；優先挖母音、母音組合（ea、ie、ou）、重複字母（ll、pp）、字尾的 e。
  初級的第一個字母一定給，中級以上第一個字母也可能挖掉。
- 星星：答對 85% 以上三顆、60% 以上兩顆、1 題以上一顆（15 題就是 13、9、1 題）。

## 單字題庫（Supabase）

題庫正本在 Supabase 專案 **3dlab** 的 `words` 資料表（Table Editor → words）：

| 欄位 | 說明 |
|---|---|
| `en` | 英文單字（只能是小寫 a–z、至少 3 個字母，因為店裡只賣這 26 個字母） |
| `zh` | 遊戲裡顯示的中文提示，越短越好 |
| `zh_full` | 字表上的完整解釋（參考用，遊戲不顯示） |
| `level` | 1 初級（國小 100 字）、2 中級（國中基礎 1200 單字裡 3–6 個字母）、3 高級（7 個字母以上） |
| `enabled` | 取消勾選就不會出題 |

- 在後台改字、改中文、取消 `enabled`，下次打開遊戲就生效，不用改程式。
- 中文提示是從字表取第一個解釋，少數手動改成較常用的意思；還沒逐字檢查過 [需確認]。
- 遊戲用的是 publishable key（公開金鑰），只能「讀」啟用中的單字，不能新增或修改（權限設在資料表的 RLS）。
- `scripts/words.js` 裡有一份內建備份。連不上 Supabase（沒網路、直接雙擊開檔案、專案被暫停）時改用它；備份不會自動跟著後台更新。
- **免費方案的專案 7 天沒有人用會被暫停**，暫停時遊戲照樣能玩（用內建備份），到 Supabase 後台按「Restore」就恢復。

## 寫法約定

- 色彩、字級、間距、尺寸、時間都從 `styles/tokens.css` 引用，元件裡不寫死色碼或 px（border 的 1px 例外）。
- 3D 場景以「Figma 的 1px」為單位：`--su` ＝ 舞台寬度 ÷ 1200，舞台多寬場景就多大。
- 斷點只用 375／768／1200。手機版舞台撐滿整個螢幕。
- 沒有任何函式庫。JS 只產生重複出現的東西、決定遊戲流程的順序；動畫本身是 CSS transition／animation，狀態都寫在 data 屬性上。

## 背景音樂

`scripts/music.js` 用瀏覽器內建的 Web Audio 現場合成，沒有任何音檔，曲子是自己寫的原創，不涉及版權。
84 BPM、F 大調、16 小節一輪（約 46 秒）不停循環：電鋼琴琶音、軟軟的弦樂墊底、鈴聲旋律、圓圓的貝斯、輕輕的鼓（反拍稍微晚一點，比較慵懶）。
氣氛參考療癒系經營、料理小遊戲的店內音樂。瀏覽器規定使用者點過畫面才能出聲，所以第一次點遊戲（例如店門）才開始播；右上角可以開關，選擇記在這台瀏覽器裡。

## Figma → CSS

| Figma | CSS |
|---|---|
| 3D transform（Depth、X／Y／Z 旋轉） | `transform: translateZ() rotateX() rotateY() rotateZ()`，順序相同 |
| Keep nested layers 3D | `transform-style: preserve-3d` |
| Perspective | `perspective` |
| 背面不顯示 | `backface-visibility: hidden` |

### 為什麼店分成好幾層

整間店、店面全部放在同一個 3D 空間時，Chrome 排前後會出錯：某些舞台寬度下牆被漏畫一塊、店面右半邊被截掉、店裡的牆被畫到店外。
所以地板、天花板、每一面牆、擺設、店面、顧客……各自一層 `.shop__room`（套同一個鏡頭），依固定順序疊起來。
挑的順序都是「後面那層不可能擋住前面那層」，例如鏡頭永遠在牆面圍起來的那一側，所以擺設一定疊在牆面上面。
